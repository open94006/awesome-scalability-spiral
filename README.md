# 擴展螺旋

把 GitHub 上的 [awesome-scalability](https://github.com/binhnguyennus/awesome-scalability) 閱讀清單整理成一條由淺入深的大型系統學習路徑。以 React、TypeScript 與 Vite 打造，學習進度與筆記存在本機的 SQLite。

## 學習路徑：知識 → 習慣 → 技能 → 智慧

四個階段不是四個分類，而是一路往上、範圍越來越大的階梯：

| 階段 | 要照顧的範圍 | 內容 | 單元／課數 |
| --- | --- | --- | --- |
| 第一階 知識 | 一個概念 | 規模、延遲、一致性、資料分布、設計原則 | 5 單元／47 課 |
| 第二階 習慣 | 一個服務 | 效能量測、逾時、斷路器、隔離、限流、負載平衡、容錯移轉、自動擴展、韌性 | 10 單元／102 課 |
| 第三階 技能 | 一組分散式元件 | 快取、資料庫、儲存、搜尋、訊息、排程、可觀測性、資安、微服務、交付、效能調校、巨量資料與機器學習 | 40 單元／631 課 |
| 第四階 智慧 | 整個系統與團隊 | 取捨判斷、架構案例、面試、演講、團隊與工程文化 | 11 單元／136 課 |

上游目錄的 10 個分類、916 個不重複連結全部收錄，每一課都標示原目錄分類。

- 每個單元以一個問題開場，讀完要能回答它。
- 每一課只留**中文標題、英文原標題、摘要、三到五個重點**。重點可以逐條複製，也可以一鍵複製成「AI 提問」，貼到 AI 對話請它舉例與出題。
- 每一課都有「我的筆記」，自動儲存；「學習紀錄」頁依日期列出完成的課與筆記。
- 按下「完成，下一課」會自動往下走；讀完一個單元會先停在下一個單元的開場問題，讀完一個階段會先看下一階的「晉階檢核」。

## 開始使用

需要 Node.js 22.18 以上（使用內建的 `node:sqlite`，不需另外安裝資料庫）。

```bash
npm install
```

```bash
npm run study
```

`npm run study` 會在背景啟動本機伺服器（已經開著就不重開），並用預設瀏覽器打開 <http://localhost:5173>。伺服器紀錄寫在 `data/server.log`。要關掉伺服器：

```bash
lsof -ti:5173 | xargs kill
```

在 macOS 上想點兩下就開啟，可以在桌面建立一個 `.command` 檔，內容執行 `scripts/study.sh` 即可。

## 學習進度與筆記

- 存在 `data/progress.sqlite`，由 Vite 伺服器上的 `/api` 讀寫（見 `vite.config.ts`）。
- 以這台電腦的 MAC 位址辨識學習者（macOS 讀硬體位址，其他系統讀第一張網卡），同一台電腦的所有瀏覽器與無痕視窗共用一份進度。
- 只在 `npm run study`、`npm run dev`、`npm run preview` 時可用；若把 `dist/` 當純靜態網站部署，進度只會存在瀏覽器的 localStorage，筆記與學習紀錄無法使用。
- `data/` 已列入 `.gitignore`，不會被提交。

安全設計：伺服器只聽本機連線；拒絕帶有其他網站 Origin 的請求，避免你瀏覽的網頁偷改進度；`/data/` 底下的檔案不對外提供；請求內容上限約 20 萬字；所有查詢皆為參數化語句。

## 連結檢測

上游目錄有許多文章已經搬家或下架。`scripts/check-links.mjs` 會逐一檢測，分成五種狀態：

| 狀態 | 意義 | 網站上的處理 |
| --- | --- | --- |
| 正常 | 可以直接閱讀 | 開啟原文 |
| 已搬家 | 原網址失效，但找到文章的新網址 | 改連到新網址 |
| 文章已不在 | 頁面打得開，但被導到首頁、列表頁、登入頁，或網域已易主 | 提供網頁封存版與搜尋建議 |
| 連結失效 | 404、410、網域不存在、連不上 | 提供網頁封存版與搜尋建議 |
| 無法確認 | 網站阻擋自動檢測 | 照常提供連結 |

2026 年 9 月 30 日的檢測結果：正常 780、已搬家 78、文章已不在 21、連結失效 37；58 條有問題的連結中，49 條找得到網頁封存版。Medium 這類網站對程式請求一律只回空殼頁，因此另外用真實瀏覽器逐條複核，結果記錄在 `scripts/link-overrides.json`，重新檢測時會沿用。

## 其他指令

| 指令 | 用途 |
| --- | --- |
| `npm run build` | 型別檢查並打包到 `dist/` |
| `npm run check:links` | 重新抓取上游目錄並檢測所有連結，更新 `src/data/links.json`（約 5 到 10 分鐘） |
| `npm run check:content` | 確認課程完整涵蓋上游每個網址、每課重點為三到五項，並掃描簡體字與大陸用語 |

## 檔案結構

- `src/curriculum/`：四個階段的課程內容（每課一列：網址、中文標題、摘要、重點），`index.ts` 負責組裝並接上連結檢測結果。
- `src/data/links.json`：上游目錄結構與每個連結的檢測結果。
- `src/App.tsx`：學習路徑側欄、總覽、階段、單元、課題、筆記、學習紀錄、搜尋與連結健康度頁面。
- `src/DesignGuide.tsx`、`src/styles.css`、`DESIGN.md`：設計規範。
- `vite.config.ts`：學習進度與筆記的 SQLite 介面。
- `scripts/`：連結檢測、內容檢查與啟動腳本。
